## 대상과 목적

- **서비스:** 지역 이삿짐센터 (포장이사·반포장·일반·사무실 이사)
- **주 사용자:** 이사를 앞둔 30~50대 가구, 대부분 휴대폰으로 접속
- **화면의 핵심 역할:** 믿을 만한 업체라는 확신을 주고, **견적 신청** 또는 **전화 상담**으로 바로 이어지게 한다

## 방향: 미니멀 (2026-10-03 사용자 요청으로 변경)

군더더기 없이 깔끔하게. 장식은 빼고 여백, 글자 크기, 가는 구분선만으로 구조를 보여준다.

- **장식 없음:** 테이프 띠, 그라데이션, 그림자, 장식용 이미지는 쓰지 않는다. (초기안의 간판체 제목과 테이프 띠는 제거했다.)
- **글꼴 하나:** IBM Plex Sans KR 하나로 굵기와 크기만 바꿔 위계를 만든다.
- **노랑은 행동에만:** 안전 노랑은 "견적 신청" 버튼에만 쓴다.
- **섹션 구조:** 왼쪽 1/3에 섹션 제목, 오른쪽 2/3에 내용. 섹션 사이는 가는 선(line) 하나로 나눈다. 카드 상자 대신 구분선 목록을 쓴다.
- **번호는 순서가 있을 때만:** 이사 절차처럼 실제 순서가 있는 내용에만 번호를 붙인다.
- **박스처럼 단단한 모서리:** 카드와 패널은 4px, 입력칸과 버튼은 6px. 둥근 알약 모양은 상태 배지에만 쓴다.
- **글은 왼쪽 정렬:** 한 줄은 한글 기준 40자 안팎, `word-break: keep-all`.
- **전화번호는 크게:** 헤더, 문의 섹션, 푸터에 전화번호를 크게 노출하고, 모바일에서는 하단 고정 버튼(전화 상담, 견적 신청)을 둔다.

## 색상

| 이름 | 값 | 용도 |
|---|---|---|
| ink | `#172033` | 본문 글자, 제목 |
| ink-soft | `#4f5b70` | 보조 글자 (paper 배경 대비 약 6.6:1) |
| paper | `#f6f7f9` | 페이지 배경 |
| surface | `#ffffff` | 카드·입력칸 배경 |
| line | `#d8dde6` | 테두리·구분선 |
| truck | `#1e47c8` | 기본 버튼, 링크, 포커스 표시 (흰 글자 대비 약 7:1) |
| tape | `#f4c21b` | 견적 신청 버튼 전용 (ink 글자 사용) |
| danger / success / warning | `#c42b2b` / `#1f7a4d` / `#8a5a00` | 오류, 완료, 진행 중 상태 |

라이트 모드만 지원한다. 다크 모드는 운영 이후 필요하면 검토한다.

## 글꼴

| 글꼴 | 역할 |
|---|---|
| IBM Plex Sans KR 400/500/700 | 제목, 본문, UI 전체 (`font-sans`). 제목은 700 + `tracking-tight` |

크기 단계: 12 · 14 · 16(본문) · 18 · 20 · 24 · 36 · 48 · 72px. 본문 줄 간격은 1.6.

## 컴포넌트

`components/ui/`

- `Button`, `ButtonLink`: primary / accent(견적 신청 전용) / outline / ghost / danger, 최소 높이 44px
- `Field`: 라벨, 필수 표시, 도움말, 오류 메시지를 `aria-describedby`·`aria-invalid`로 연결
- `Input`, `Textarea`, `Select`
- `Checkbox`, `RadioGroup` (선택지를 큰 타일로 표시)
- `Card`, `Badge` (신청 상태 표시)
- `Dialog` (네이티브 `<dialog>`), `Toast` (`aria-live` 알림)

개발 중에는 `/dev/ui`에서 모든 컴포넌트를 확인할 수 있다 (운영 빌드에서는 404).
