# data/ — 개발용 mock 데이터

이 폴더의 JSON은 **화면 개발용 가짜 데이터**다.

- `live-quotes.json`: 실시간 견적현황 (가짜 이름, 지역)
- `reviews.json`: 고객 후기 (지어낸 후기)
- `services.json`, `steps.json`: 서비스, 진행단계 문구 (회사 확인 필요)
- 실시간 견적의 `status`는 문의접수 / 진행중 / 완료 세 가지다.

**운영 배포 전 필수:** 지어낸 후기나 실시간 현황을 실제 사이트에 노출하면 표시광고법 위반 소지가 있다.
실시간 견적은 DB의 실제 신청 내역(이름 마스킹)으로, 후기는 실제 고객 후기로 바꾸거나 해당 섹션을 내린다.
